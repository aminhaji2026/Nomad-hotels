# Nomad Hotels

Long-stay hotel discovery for digital nomads — filter by destination, Wi‑Fi speed, and stay length, then browse work-ready rooms with monthly pricing.

> Design note: inspiration images and a build brief were referenced in the original request but were not available in this environment (upload skipped). This first version is based on the `Nomad-hotels` product name and common nomad-stay product patterns.

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

```bash
npm run build   # production build
npm run preview # preview the build
```

## What’s included

- Home landing with full-bleed hero and brand-first composition
- Search by city, minimum Wi‑Fi, and stay length
- Explore results with nomad-relevant tags (desk, kitchen, cowork)
- Stay detail pages with work-ready facts and monthly pricing
- Static mock inventory in `src/data/hotels.ts`
